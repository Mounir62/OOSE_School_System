# 🎓 OOSE Student Management System

A modern, object-oriented **Student Management System** developed using standard **OOP principles**, **software engineering methodologies**, and **design patterns**. This project simulates the core operations of a school, including student, course, and instructor management.

---

## 📌 Features

* 🔐 User roles: Admin, Instructor, Student
* 📘 Course management (add, assign, enroll)
* 🧑‍🎓 Student enrollment and info tracking
* 🧑‍🏫 Instructor assignment and class overview
* ✅ Console-based interaction and simple UI
* 🧱 Built using SOLID principles and GoF design patterns

---

## 🏗️ System Architecture

The project emphasizes:

* ✅ **Abstraction & Encapsulation**
* 🧱 **Inheritance & Polymorphism**
* 🔁 **Design Patterns:**

  * Singleton (for system controller)
  * Factory Method (for object creation)
  * Observer (for notification/updates)
  * MVC structure (modular separation of UI, logic, and data)

---

## 🧾 Core Modules

* `Main.java` – Launches the system
* `models/` – Data classes (Student, Instructor, Course...)
* `services/` – Business logic and operations
* `controllers/` – Input management and process handling
* `interfaces/` – Abstract behaviors & contracts
* `utils/` – Helper functions and reusable logic

## 🚀 Getting Started

### Prerequisites

* Java SDK 8+
* IDE: IntelliJ, Eclipse, or VS Code

### Run Instructions

1. Clone the repository:

   ```bash
   git clone https://github.com/Mounir62/OOSE_School_System.git
   cd OOSE_School_System
   ```
2. Open the project in your IDE
3. Run `Main.java`
